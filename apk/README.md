# LanScreen TV 1.3.2 预编译安装包

本目录保留原 1.3.2 APK，业务代码与签名未因文档脱敏而变更。

- 包名：`com.lanscreen.player`
- 版本：`1.3.2`，versionCode `6`
- 最低 Android API：23
- 签名身份：`LanScreen Local Demo`
- 不包含签名私钥；对应公开证书包含在 APK 中，这是 Android 安装校验所需信息。

安装前按 `SHA256SUMS.txt` 校验文件。电视必须允许安装第三方 APK；厂商安装限制仍适用。覆盖安装应核对现有应用签名，保留设备身份需要保留应用数据。

自行构建会生成新的本地演示签名，除非使用原签名私钥，否则不能据此保证覆盖安装本目录 APK。正式维护应使用自己长期保管的签名私钥，不将 keystore 或签名密码提交到仓库。

本次公开包整理没有重新构建 APK，也没有进行新的实机安装、断电恢复或多日连续播放验收。静态隐私检查范围见 `../docs/隐私与发布说明.md`。
