电视缓存设置

新清单成功切换后，电视会自动清理不再使用的素材。手动清理同样会保护当前清单和正在准备的新清单。

设置适用于已升级的电视。新旧清单需要短暂共存；空间不足时会保留当前播放内容，并回报更新失败。1 MiB = 1024 × 1024 字节。

连接一台电视

安装应用，填写服务地址与播放密钥。

01

安装电视应用

将交付包里的最新版 APK 拷贝到 U 盘，在电视上安装“局域宣传屏”。1.3.0 以前的旧版电视升级后需要重新申请接入。

02

填写服务地址

电脑和电视需能访问同一台 NAS 或 Mac 的局域网地址。

03

填写播放密钥

此共享播放密钥用于电视接入申请与同步，不具备后台管理权限，请保存在内部。首次连接时在电视上提交绑定申请，再到“电视设备 → 待审批”批准；批准后电视会自动管理本机的独立授权，开始同步素材。

12～128 个字符，仅可使用大小写字母、数字和 ._~-。避免使用公司简称或连续、重复字符，推荐生成安全随机密钥。

保存后，当前服务实例会立即停止接受旧密钥发起的新请求，每台电视都需重新填写。仅在服务端更换密钥不会撤回电视已有的离线缓存；电视填写并保存新密钥后会重新同步，期间可能中断播放。请在网络稳定时逐台更换。

04

批准电视并发布清单

先在“电视设备 → 待审批”核对并批准电视，再回到素材与编排，上传并预览素材，再加入清单发布。电视按原比例全屏显示，空白区域为黑色。

素材准备

PDF、PPT / PPTX 会转换为静态页面。PPT 的动画、音频及嵌入视频请先导出为 MP4；推荐 H.264 视频编码与 AAC 音频编码。首次发布前请检查中文字体和页面排版。
